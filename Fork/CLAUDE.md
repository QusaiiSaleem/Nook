# Fork notes (branch `qusai`)

Imported by the last line of `CLAUDE.md`. Notes for fork-only code live here, so official releases merge
cleanly (`Fork/README.md`). Build with `Fork/build.sh` (bundle id `com.qusai.nook`, ad-hoc signed):
wherever `CLAUDE.md` says `com.gstudios.nook`, this build uses `com.qusai.nook`.

- **Arc import.** `ImportManager/Arc.swift` walks Arc's sidebar JSON in Arc's order: favorites per space, nested folders, titles (Arc's `title` is the person's rename, `savedTitle` the page title), space colors, and split views as saved splits. `Fork/verify-arc-import.py` compares item by item, skipping deleted spaces (tombstones with `deletedAt`). Upstream merged its own importer with this one (PR #393): on the next release, take upstream's importer and re-add the saved-split creation.
- **Saved splits.** A folder `Item` with `split: SplitInfo{fraction, focusRight}` (formatVersion stays 2, so older builds see a folder); rules in `TabTree+Splits.swift`, row `SavedSplitRow`, divider `SplitDividerView` (25–75%, double-click for 50/50). Holding a dragged tab over a row's middle third for 0.35 s makes one.
- **Capture.** Full page: `BrowserManager+Capture.swift` (`WKWebView.pdf` → PNG through downloads and the clipboard). Area: `Nook/Components/AreaCapture/` (drag, or click an element; Arrow and Highlight).
- **Magic Mouse.** The space pager no longer requires `NSEvent.isSwipeTrackingFromScrollEventsEnabled`, which is false for a Magic Mouse one-finger swipe.
- **Web notifications and unread counts.** Page side `WebNotificationScripts` + `WebNotificationBridge` (NookWeb), policy `WebNotificationPolicy`, app side `WebNotificationManager`. Unread counts come from the page title (`UnreadCount`, `PageSession+Unread`, `UnreadBadge`).
- **WhatsApp local copy.** Per space, "Keep a Local Copy" in the WhatsApp site menu (`LocalCopyMenuRows`). WA-JS (`wppconnect-wa.js`, pinned by SHA-256 in `Fork/update-wa-js.sh`; Google Analytics off through a `WPPConfig` prelude) runs in the page world. `MessageArchiveScripts` only reads (it never sends, marks read or changes what others see) and posts records to a relay in an isolated world. `MessageArchiveManager` writes them to `Messages/messages.sqlite` (FTS5 over Arabic-normalized `SearchText`) on a serial queue. On load it backfills what WhatsApp Web holds on this Mac, then saves each new message. Messages deleted for everyone and expired disappearing messages are removed; view-once media is never saved; media older than 30 days is held back. `Messages/` is excluded from Time Machine. `MessageArchive.search` has no caller yet.
- **Auto-archive.** A tab in a space's Today section that nobody looked at for 12 hours (`AutoArchive.maxAge`) closes into History. Favorites, pinned tabs, split tabs and the Agent space never archive.
- **Idle unload.** `IdleUnloadPolicy` decides which hidden pages may unload (idle timeout, memory pressure, the Power Saving budget). Favorites and pinned tabs unload too, unless the page keeps running for alerts, has shown an unread count, is WhatsApp with the local copy on, holds typed text (`hasTypedSinceLoad`, reset on commit), or is in full screen. Power Saving's app-switch unload skips favorites.
- **Mobile View.** ⋯ More → Mobile View (`PageSession.setMobileView`). The web view is narrowed to 390 pt and centered (`MobileView.frame(in:)`; `obscuredContentInsets` was not used because it draws left-aligned), and every view of the page gets an iPhone Safari user agent and reloads (`iPhone OS 18_6`, the token WebKit freezes). No touch emulation.
- **Space marks.** A space may carry `SpaceRecord.mark`: an emoji, or a 64 px PNG drawn once, off the main thread and within 1 s, from an SVG the person picked (`SpaceMarkRenderer`; `SpaceMark.acceptsSVG` refuses files over 64 KB and `<use>`, `<filter>`, `<image>`, `<foreignObject>`, entities). It replaces that space's dot in the switcher (`SpaceMarkView`), set from Settings > Spaces (`SpaceMarkPicker`); spaces without one keep the dot. It is its own field because `icon` carries the Agent space's marker. A mark kind this build does not know decodes as none rather than failing the tab file; a build from before marks drops them on its next save. Never draw the SVG itself in a view: a 141-byte SVG took 1 GB per draw.
- **Mic and camera.** Upstream ships without `NSMicrophoneUsageDescription`/`NSCameraUsageDescription` and the `device.audio-input`/`device.camera` entitlements, so `navigator.mediaDevices` was undefined and Meet said "Mic not found". The fork adds both to `Info.plist` and both entitlements files; WebKit then exposes media devices with `mediaDevicesEnabled` still unset (measured on macOS 27: `enumerateDevices` lists audioinput and videoinput, no WebContent crash). Not upstreamed yet.
- **Agent testing tools (DevMCP).** In `Nook/Managers/DevMCPServer/Testing/`:
  - `inspect` renders an http(s) URL in its own off-screen window at 390/820/1280/1600 pt and in dark mode, as a visitor without Nook's blocker. It takes an optional slow-network profile (through `ThrottleProxy`, in a throwaway data store) and has its own 60 s deadline.
  - `type` and `upload` act on the agent's tab; `upload` refuses hidden paths and anything under `~/Library`.
  - `record_start`/`record_stop` make a GIF (1–10 fps, at most 60 s).
  - Agent pages park after 30 s idle and sleep after 5 min (`BrowserManager+Agent.swift`).
  - Checks: `scripts/tests/{InspectRunner,InspectReport,InspectScripts,AgentInput,GIFRecorder,ThrottleProxy,DevMCPFiles}Check.swift`.
